# P12 Example

The classes in this folder provide an example of implementing P12 authentication, using the same classes as the CJL library.

Note they are provided as examples to help partners implementing their own SAP Commerce code. If you are using CyberSource SAP Commerce plugin with isv-payment-api.jar, then this functionality is built in and you won't need these examples.
